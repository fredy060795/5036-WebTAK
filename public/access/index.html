    Set up your app

    1. Install ATAK-CIV from Google Play and open it once (allow location).
    2. Tap ☰ → Settings → Network Preferences → Manage Server Connections.
    3. Tap ⋮ → Scan QR Code and scan this code (on the same phone: take a screenshot and use Import from image, or print the page).
    4. ATAK requests its certificate and connects. A green indicator (bottom right) means you are online.
    5. Disconnect and reconnect once – the server then sets your callsign and team.
