    Set up your app

    ★ Recommended: WebTAK – works right away in the browser on any phone, tablet or PC. Nothing to install from an app store, your server and login are filled in automatically. ATAK and iTAK are optional.

    1. Scan this code with the phone camera – or on the phone tap Open WebTAK
    2. The app opens with your server already set and requests its certificate automatically. If asked about an unknown server certificate, tap TRUST (or load the truststore first).
    3. Add it to your home screen: Android Chrome ⋮ → Add to Home screen, iPhone Safari Share → Add to Home Screen.
    4. Green square bottom right = connected. Tap the marker icon at the top to place markers, the menu icon for everything else.

    No typing needed: server, user, password, callsign and certificate come in one setup package.

    1. Install ATAK-CIV from Google Play and open it once (allow location).
    2. Scan this code with the normal phone camera and open the link – or on the phone tap ⬇ ATAK setup package
    3. Open the downloaded file with ATAK (tap the download notification). ATAK imports everything, requests its certificate and connects – green indicator bottom right = online.

    Server with a public certificate (e.g. Let's Encrypt)? Then ATAK can also enroll directly: open in ATAK or scan this QR code in ATAK (Network Preferences → Manage Server Connections → ⋮ → Scan QR Code).

    Menu names can differ slightly between ATAK versions. Manual setup: Add server → address , protocol SSL, port , tick Use authentication and Enroll for client certificate, enter user and password above.

    Phone or controller screen

    Browsers cannot capture a phone screen. Use an app such as Larix Screencaster (Android) or Larix Broadcaster, add a connection with the RTMP address above and start. On a PC you can share the screen directly in WebTAK (Video → Share screen).
