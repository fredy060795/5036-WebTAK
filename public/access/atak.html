WebTAK Access

Set up ATAK in two taps

This package contains everything: server, your login, callsign and the server certificate. You do not need to type anything.

  1. ⬇ Download ATAK setup package
  2. Open the downloaded file with ATAK – tap the download notification (or open it in the Files / Downloads app) and choose ATAK. Alternatively in ATAK: ☰ → Import → Local SD → Download → WebTAK-….zip.
  3. ATAK imports the package, requests its certificate and connects. A green indicator (bottom right) means you are online.

No ATAK yet? Install ATAK-CIV from Google Play, open it once, then come back to this page. iPhone: the same package can be opened with iTAK.

Alternative: open directly in ATAK

Only works if the server has a publicly trusted certificate (e.g. Let's Encrypt). Otherwise use the package above.
