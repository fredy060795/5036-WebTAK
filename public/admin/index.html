Users & requests

StatusName / unitCallsignTeam / roleOTS userDevicesRequested

Default: everyone sees everyone. Every user is in the OTS group of their team (TEAM_…) with IN + OUT (send and receive) and reads the groups of the other teams. Untick = this team does not see the other one: OTS stops delivering positions, markers and chats of the hidden team. Devices have to reconnect afterwards. Single users can be set to "receive only" or "send only" under Users → Edit.

OpenTAKServer

New TAK accounts

Recommended: leave empty – every account gets its own random password. It is shown on the access page and included in the ATAK setup package, the user does not have to type it. One fixed password for everyone is insecure.

Approved users get the OTS group of their team with IN + OUT, so they can communicate (positions, markers, chat, direct messages). With this switch they also exchange with users created by hand in OTS, which are in the default group __ANON__. Per user "receive only" / "send only" under Users → Edit.

ATAK finds the streams under Video (rtsp://<TAK server>:8554/<path>). The path is built automatically from the name – only change it if needed. Green dot = registered.

Links & QR codes

Registration – new users

Users send a request here; you approve it under "Users & requests". They then get login details, QR codes and a guide.

WebTAK app – map, chat, video in the browser

For users with access. Video (phone/helmet camera) starts right in WebTAK and appears as a feed in the TAK server automatically.

Camera app – camera only, without TAK access (helmet camera, phone as camera)

For cameras without their own TAK access: scan, enter name and unit, connect the camera, start the stream – the feed appears in the TAK server automatically. Users with access start video right in WebTAK.

Create stream

Optional – for a fixed helmet camera with its own QR code. Usually users sign up themselves.

WebTAK app (settings – link and QR code under "Links & QR codes")

Users connect with their own TAK credentials (certificate enrollment, .p12 / data package or QR code from the TAK server). This server only relays the data – certificates stay on the phone and are not stored here.

OTS users (all accounts in the TAK server)

All users from OpenTAKServer – including those created directly in OTS. "Import" additionally manages a user in WebTAK (callsign, team, access page with QR codes).

Groups (OTS channels)

Members with IN send into a group; members with OUT receive it. Users without a group are in __ANON__. Manage memberships under "OTS users" → Groups.

All feeds in the TAK server (OpenTAKServer/MediaMTX)

These are all feeds ATAK/iTAK/WinTAK see under "Video" – the cameras from WebTAK (above) and other sources. Add another feed: OTS/MediaMTX pulls the video on demand from the source (camera, drone, another server) and provides it as rtsp://<TAK server>:8554/<path>. Without a source the path waits for a camera that sends to it itself.

🚁 Send a drone (DJI), OBS or screen app directly to the TAK server

Nothing to create: whoever sends to a path with their TAK user and password shows up as a feed right away. Users find their ready-made address on their access page and in WebTAK under Video.
